# Bold Dragoon CC Hub — Version 12.0 Complete Club App

This is the complete non-Play-Cricket version.

Included:
- Professional five-tab mobile navigation
- Live Rushmere Road weather
- Manual fixtures and results
- Ground calendar, training, bookings and clash checks
- Teams and member directory
- Availability and team selection
- Club news and announcements
- Message centre with junior consent controls
- Secure Supabase accounts and committee approval
- Volunteer rota, membership status, contacts, documents and sponsors
- Ground open/restricted/closed controls
- Admin centre and floating quick-add menu
- Installable PWA for iPhone and Android
- Setup checklist inside the app

Still pending:
- Play-Cricket API automatic fixtures, results, tables and statistics
- True native push notifications/App Store packaging

Required setup:
1. Upload all files to the GitHub repository.
2. Wait for Netlify to publish.
3. Run SUPABASE_SETUP.sql if the shared club database is not already working.
4. Run SUPABASE_SECURE_AUTH.sql.
5. Enable Email authentication in Supabase.
6. Create the first account and approve it as committee.
